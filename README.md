# Block Puzzle

A Block Blast-style puzzle game for Scratch, written in TypeScript with [TextToScratch](https://github.com/KashTheKing/TextToScratch).

Drag the three pieces from the tray onto the 8×8 board. Fill a whole row or column to clear it; clearing several at once scores a combo.
The game ends when none of your pieces fit.

**Play it:** download [block-puzzle.sb3](https://kashtheking.com/text-to-scratch/examples/block-puzzle.sb3) and open it in Scratch
(**File → Load from your computer**).

## Build

This project uses the TextToScratch compiler from a sibling folder:

```bash
git clone https://github.com/KashTheKing/TextToScratch.git
git clone https://github.com/KashTheKing/block-puzzle.git
```

```bash
cd TextToScratch && npm install && npm run build
```

```bash
cd ../block-puzzle && npm install && npm run build
```

Then open `dist/block-puzzle.sb3` in Scratch.

## Layout

| Path | What it is |
|---|---|
| `src/Game.ts` | all game logic and rendering (pen stamps) |
| `src/Stage.ts` | shared score / best score |
| `src/Thumbnail.ts` | title card (also the Scratch thumbnail) |
| `src/Game/*.svg` | block, board and panel costumes |
| `src/Game/*.wav` | sound effects (generated by `npm run sfx`) |
| `src/Stage/background.svg` | backdrop |

## Scoring

- 1 point per block placed
- 10 × lines² for clearing lines (1 line = 10, 2 = 40, 3 = 90, …)
