# Block Puzzle

A Block Blast-style puzzle game for Scratch, written in TypeScript with [TextToScratch](https://kashtheking.com/text-to-scratch/).

Drag the three pieces from the tray onto the 8×8 board. Fill a whole row or column to clear it; clearing several at once scores a combo.
The game ends when none of your pieces fit.

## Build

```bash
npm install
```

```bash
npm run build
```

Then open `dist/block-puzzle.sb3` in Scratch (**File → Load from your computer**).

## Layout

| Path | What it is |
|---|---|
| `src/Game.ts` | all game logic and rendering (pen stamps) |
| `src/Stage.ts` | shared score / best score |
| `src/Game/*.svg` | block, board and panel costumes |
| `src/Game/*.wav` | sound effects (generated by `npm run sfx`) |
| `src/Stage/background.svg` | backdrop |

## Scoring

- 1 point per block placed
- 10 × lines² for clearing lines (1 line = 10, 2 = 40, 3 = 90, …)
